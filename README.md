## Как пользоваться

1. Напишите **«Найдите парк для часовой прогулки»**.
2. В **«Условиях поиска»** задайте **EXPO → 5 км → 60 минут**, бюджет оставьте пустым.
3. Нажмите **«Найти места»**, откройте **«Сведения и источники»** или маршрут.

Второстепенные фильтры и демо-профили доступны в раскрывающихся разделах.

Пустой бюджет — без денежного лимита. **0 ₸** требует подтверждённо бесплатного посещения: при неизвестной цене место исключается.

## Что работает

- Разбор свободного запроса настоящим ИИ, поиск по сохранённому RAG-индексу и объяснение выбора.
- Категории и строгие ограничения; фильтры не ослабляются молча.
- **0–3 реальных места** после строгих фильтров. Неизвестные свойства не подменяются фактами.
- Краткое резюме условий; дополнительные фильтры, демо-профили и история — по раскрытию.
- Источники и отзывы как мнения; идеи занятий отделены от подтверждённых сведений.
- Маршруты в **2ГИС / Google Maps**, пешком или на машине. Геолокация — только по нажатию.
- Адаптивный интерфейс от **360 px**, клавиатурный фокус и доступные подписи.

## Данные и ИИ

**298 мест · 7 категорий · 591 короткая выдержка с источниками.** Импорт из сохранённого снимка 2ГИС/Apify от 19 октября 2026. Каталог и индекс не пересобирались ради редизайна.

Live-конвейер сохранён в коде: Mistral Small 3.2 / DeepInfra через серверный OpenRouter разбирает запрос и объясняет выбор. Он включён на одном сервере с прежним canonical учётом расходов. Vercel передаёт проверенный запрос через защищённый серверный proxy; OpenRouter-ключ и ledger остаются на Mac. Существующий неизвестный запрос учтён по отдельно разрешённому верхнему резерву $0.028096, actual остаётся неизвестным. Новая неизвестная стоимость снова останавливает платные вызовы. Embeddings — `openai/text-embedding-3-small`, индекс **298 × 1536**. Названия, рейтинги, координаты, часы и ссылки берутся из каталога; сервер проверяет ID, источники и ограничения.

## Запуск и проверки

Node.js **24.21.0**, pnpm **11.0.8**.

```sh
pnpm install --frozen-lockfile
APP_AI_MODE=stub OPENROUTER_PAID_ENABLED=false LIVE_EVAL_ENABLED=false pnpm dev
```

Без платных вызовов доступны категории и пять демо-фраз. Для live нужен серверный OpenRouter и существующий учёт расходов; [правила бюджета](docs/budget.md). Ключи, `.env`, ledger, raw/normalized и пользовательские данные не публикуются.

```sh
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm check:build-artifacts
pnpm test:e2e
pnpm exec playwright test --config playwright.disabled.config.ts
python3 scripts/check_harness.py
```

Срочное включение21октября: отдельный versioned бюджетный grant и защищённый proxy прошли независимое ревью; выполнены только целевые offline-проверки и сборка. Новых платных eval/smoke нет.

Предыдущее исправление21октября: **6 сценариев режима без ИИ и 70 прежних браузерных сценариев**, lint, typecheck, production build, strict NFT и harness прошли. Ранее при редизайне проверены1055unit-тестов. Desktop1440/mobile390/360, фильтры, пустой результат, источники, фокус и ссылки карт проверены; отдельное независимое ревью пройдено. Полный live-eval не запускался. Известные ключи в исходниках, сборке и исходящих коммитах проверены: совпадений нет. Результаты — в трекере.

## Ограничения

Интерфейс размещён на **Vercel Hobby**. **Для ИИ Mac и его туннель должны оставаться включёнными**; это временный backend, а не автономный облачный ИИ-сервис. Полная квалификация ИИ на 12 сценариях и проверка текущего URL на физическом телефоне не завершены. Голоса нет. Отзывы — мнения; цены, часы и свойства могут быть неизвестны. Право публикации исходных текстов отзывов отдельно не установлено.

Заявка уже отправлена пользователем. Повторная отправка не выполнялась.
