# Дополнительная source-first разметка на казахском

Draft для M4.1: `real-cases-kk.json` содержит четыре положительных запроса с
locale=kk, отдельно от неизменных 12 RU positive и4 negative. Это agent-curated
development set: запросы написаны агентом, не получены от реальных пользователей.
Проверка носителем казахского недоступна; nativeSpeakerVerified=false,
blindHumanBenchmark=false. Свободное понимание казахского работающей моделью
этими файлами не доказано.

Разметка подготовлена после реализации поиска, **без вызова или просмотра
retrieval/ranking/model outputs**. Сначала выбраны подтверждённые исходными
категориями и рубриками задачи, затем независимо перечислены все298 POI.
Смысловые критерии соответствуют уже source-backed задачам RU-02/07/05/12;
это языковое дополнение, а не новый независимый корпус для вывода о generalization.

## Запросы и полные множества

Все now=`2026-10-20T10:00:00Z` (вторник15:00 Asia/Almaty). Это тестовое серверное
время снаружи HTTP request. Пресеты/координаты те же, что у frozen RU labels и UI.
Максимальная длительность — оценка посещения; дорога отдельно.

Явные UI filters дополняют текст: category/radius/duration/company/openNow заданы
в explicitFilterKeys. Положительные случаи не требуют цены или amenities:
maxSpendKzt=null, requiredFacts=[]. Все неизвестные свойства остаются неизвестными.

## Источники и воспроизводимость

Каталог:298 real POI, synthetic=false, SHA256
`c72d13a1d8df327edc22adce02743b0246aec157e86330c96c408bc44fabb873`.
Frozen RU labels SHA256
`73947dd92e4b33641897321e6832ef0dad463dbe33baee4512e8be2efc5cee36`.
Normalized snapshot generatedAt=`2026-10-19T18:41:06.854110+00:00`.

В JSON приведены16 полных listing evidence entries: фактические sourceIds,
первичные2ГИС URL, collectedAt и оригинальное описание. `source-audit.json`
в draft дополнительно сохраняет исходные tags/descriptions/listing sources для
всех17 hard-eligible записей, включая исключённый art nonmatch. URL/даты сверены
с локальным сохранённым каталогом; новые live-проверки сайтов не выполнялись.
Отзывы и авторы не копировались; мнения не переводились в мнимые цитаты.
Русские listing descriptions остаются оригинальным текстом источника.

Python checker независимо использует ZoneInfo/локальные интервалы с прошлым днём,
объединяет смежные интервалы, считает Haversine(R=6371000) и все hard gates.
Отдельный Node24/Zod checker проверяет strict формы, request schemas, frozen
hashes, все refs/URL/dates, исходные snippets/tags и совпадение с filterCandidates.
Поисковый retrieve и ranking не вызываются. Все4 hard/relevant sets совпали.

Для двух полных наборов по6 ceiling Recall@5=5/6. Supplemental macro ceiling
`(1+5/6+1+5/6)/4 = 0.9166666666666667` — математический предел, не измеренная
метрика. RU denominator остаётся12 и его labels/ceiling не меняются. Supplemental
KK не добавлять молча в исходный RU score.

Явный текущий stub поддерживает пять известных русских demo-фраз. Эти четыре
неизвестных KK-фразы в stub дают clarification; наличие labels не означает
принятую Kazakh intent/semantic retrieval функциональность. Платная проверка
моделей остаётся отдельным заблокированным этапом.
