# Готовность демо на 20 октября 2026

Публичный адрес восстановлен: [открыть сайт](https://loan-begins-sleeps-unavailable.trycloudflare.com).
Проверка 20.10.2026 около 14:12 Asia/Almaty: HTTPS200, настоящий API и карточки
на мобильной ширине 390 px; базовый поиск также проверен на 1440 px.

**Рабочий текстовый демо-сценарий готов. Полная P0-версия с RAG пока не готова.**
Сейчас работают категории, пять готовых фраз и поиск по словам. Свободный текст
за пределами этих фраз просит уточнение; генеративных ИИ-объяснений нет.

## Что готово

- Адаптивный интерфейс, серверный поиск и до трёх мест из настоящего каталога.
- Точка поиска, радиус, время посещения, компания и строгие фильтры.
  Неизвестная цена не проходит заданный бюджет. Условия не меняются автоматически.
- Карточки, подробности, источники, выдержки отзывов с пометкой мнения.
- Ссылки выбранного места в 2ГИС и Google Maps для пешего и автомобильного маршрута.
- Три явно обозначенных демо-профиля, сохранение/скрытие мест и сброс истории.
  В браузере сохраняются только профиль и ID мест.
- Контроль расходов реализован и проверен; платные вызовы выключены.
- Код и PowerPoint сохранены в GitHub main; видео подготовлено локально.

## Что ещё не готово

- Реальные эмбеддинги и семантический индекс — M2.4.
- Сравнение и выбор рабочей модели OpenRouter — M4.3–M4.4.
- Проверка полного пути с реальным платным вызовом — оставшаяся часть M5.3.
  Обновлённый ключ работает: auth200 и два chat diagnostics прошли. Перед индексом
  требуется исправить точное сравнение native имени embedding-модели с OpenRouter slug.
- Голос пропущен как необязательная P1-задача.
- Постоянный хостинг, загрузка видео на YouTube и официальная отправка заявки.

Поэтому сайт выполняет проверенный сценарий выбора места, но пока не понимает
произвольные пожелания как полноценный ИИ-помощник. Следующий шаг полного P0 —
исправление embedding adapter, затем реальный индекс и live-проверки в прежних лимитах.
[Пошаговый план](live-p0-plan.md) учитывает результаты теста нового ключа.

## Данные и ключи

Использован именно `data/normalized/astana/`: все 298 мест и 591 короткая выдержка
из 1953 нормализованных отзывов включены в производный каталог приложения.
Источник — карточки 2ГИС, собранные 19.10.2026 сохранённым Apify-сборщиком.
Исходные данные и работа сборщика сохранены; повторного платного сбора не было.
Все цены и удобства вроде розеток пока неизвестны, поэтому такие строгие фильтры
могут дать ноль результатов. Это срез каталога, а не актуальная база всего города.

[Аудит датасета и ключей](security-audit.md) не обнаружил подтверждённых секретов
в проверенных данных, Git и отдаваемых клиентских файлах. Новый публичный адрес
проверен отдельно: все 12 JS/CSS-файлов совпали со сборкой, приватные пути закрыты.
Ключи не выводились; `.env.local` имеет права0600. Расход OpenRouter проекта —
$0.00024488 по трём диагностическим POST; лимит подготовки$2, внутри него live-eval$0.50,
резерв демо$4 сохранён. Это не проверка баланса аккаунта.

## Что проверено после восстановления

Реальный публичный браузер без подмены API выполнил восемь запросов:
на 390 px — поиск трёх парков, бюджет0→ноль, явное снятие бюджета без запроса,
повторный поиск→три, профиль, сохранение, скрытие и неизвестный текст→уточнение;
на 1440 px — базовый поиск трёх парков. Отдельно проверены подробности, источники,
координаты обеих карт в двух режимах, хранение ID, reload/reset без автопоиска.
Независимый SPEC/QUALITY review пройден в указанных границах.
Горизонтального скролла и ошибок страницы не обнаружено. Интегратор просмотрел
актуальные мобильные и настольный снимки. Предыдущие проверки той же сборки:
554 unit-теста и 64 браузерных сценария; lint/types/build/NFT прошли.

На физическом телефоне пользователь ранее подтвердил три карточки и открытие
выбранного Ботанического сада обеими картами в приложениях на той же сборке.
Для нового адреса пользователь подтвердил: «Открылся, три карточки есть».
Повторный переход в приложения карт не сообщался; устройство и браузер не указаны.

Для показа: **EXPO → «Хочу погулять» → 5 км → бюджет пустой → «Найти места»**.

подтверждённо бесплатного посещения и сейчас даёт ноль.
