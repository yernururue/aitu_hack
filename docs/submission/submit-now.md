## Описание для формы

«Куда в Астане» помогает выбрать до трёх мест из каталога298реальных мест по локации, запросу и ограничениям. Сервер разбирает текст через Mistral Small3.2, применяет строгие фильтры и семантический поиск по сохранённым эмбеддингам, затем проверяет ID и источники объяснений. Факты берутся из каталога; отзывы явно обозначены как мнения, идея занятия — как предложение. Неизвестные цены и свойства остаются неизвестными. Маршрут открывается в2ГИС/Google Maps.

Данные: сохранённый пользовательский снимок2ГИС/Apify19.10.2026 —298мест/1953отзыва →298POI/591короткая выдержка/7категорий. Повторного сбора не было. Стек: Next.js/React/TypeScript/Tailwind/shadcn/Zod, OpenRouter, файловый каталог и индекс298×1536.

## Показ за две минуты

1. Открыть live-демо. Ввести свободный текст **«Найдите парк для часовой прогулки»** — не нажимать старую stub-фразу.
2. Выбрать **EXPO →5км →60мин**, бюджет оставить пустым. Нажать «Найти места».
3. В принятом прогоне получены **Ботанический сад и Президенттік саябақ**. Результатов может быть0–3; не обещать обязательно три.
4. Открыть «Подробности», показать источники и пометку мнений. Выбрать «Пешком»/«На машине» и2ГИС/Google Maps.
5. Второй проверенный запрос: **«Нужно кафе, обязательно с розеткой для ноутбука»** →0мест, потому что розетки не подтверждены. Условие не ослабляется.

Бюджет0 требует подтверждённо бесплатного места; пустое поле означает отсутствие лимита. Для прогулки оставьте поле пустым.
