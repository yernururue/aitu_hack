# Границы демонстрационной версии

Версия — проверенный текстовый **offline/stub preview** на настоящем каталоге.
Semantic retrieval принят локально; полный P0 с настоящим ИИ ещё не принят. Машиночитаемое состояние и точные
хеши — в [release-manifest.json](release-manifest.json), статусы — в
[tracker.yaml](../../tracker.yaml).

- Текстовый демо-разбор поддерживает только пять видимых точных фраз. Неизвестный
  текст возвращает уточнение без карточек. Категории работают без ключа. В интерфейсе
  явно показан stub; автоматической подмены ошибочного live-вызова на stub нет.
- Реальный index298×1536 и12queryvectors локально приняты; semanticgatePASS.
  На публичном stub он ещё не включён. Actual live model=null; original72 и amended48 не завершены.
  Новая разрешённая Qwen24 квалификация остановлена на первом intent HTTP429/no-cost,
  1 POST/0 retries/нет accepted prose. Настоящий end-to-end smoke не выполнен. Nativeembeddingalias уже исправлен; это больше не блокер.
- Лексический retrieval:12/12top3, macroRecall@5=97.22%, micro=93.75%; четыре
  отрицательных сценария отдельно прошли. Это agent-curated development set из12RU,
  не blind benchmark. Дополнительные4KK — отдельная оценка; live-понимание языка и
  native-speaker проверка не выполнены. NumericalPASS не заменяет semantic gate:
  Текущий real-index `pnpm eval:retrieval` возвращает exit0/semanticacceptance=true;
  прежний lexical-onlyexit1сохранён какисторическийsnapshot.
- 298 POI — сохранённый срез, не весь город и не live-справочник. Все цены и свойства
  вроде розеток/тишины неизвестны; строгие требования исключают такие места.
  Бюджет0 означает только подтверждённо бесплатные места; пустое поле — без лимита.
  Поэтому0 исключает весь текущий каталог с неизвестной ценой.
  Расписание историческое, без праздничных исключений и гарантии фактической работы.
  Расстояние — по прямой, время посещения — оценка, дорога рассчитывается картами.
- 591 короткая буквальная выдержка отзывов — мнения, не подтверждённые свойства.
  Источник — карточка филиала, не проверенный permalink конкретного отзыва.
  Сбор данных не устанавливает право на публикацию чужого текста; такое право
  отдельно не подтверждено. Фото, авторы, контакты и полные raw-тексты не включены.
