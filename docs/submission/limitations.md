# Границы демонстрационной версии

Версия — проверенный текстовый **offline/stub preview** на настоящем каталоге.
Полная P0 RAG acceptance пока не достигнута. Машиночитаемое состояние и точные
хеши — в [release-manifest.json](release-manifest.json), статусы — в
[tracker.yaml](../../tracker.yaml).

- Текстовый демо-разбор поддерживает только пять видимых точных фраз. Неизвестный
  текст возвращает уточнение без карточек. Категории работают без ключа. В интерфейсе
  явно показан stub; автоматической подмены ошибочного live-вызова на stub нет.
- Настоящего embedding index нет, actual live model=null. OpenRouter auth ранее
  вернул401; пользователь подтвердил отсутствие нового ключа и продолжение со stubs.
  Повторных auth/paid вызовов не было. Luna остаётся кандидатом, победитель не выбран.
- Лексический retrieval:12/12top3, macroRecall@5=97.22%, micro=93.75%; четыре
  отрицательных сценария отдельно прошли. Это agent-curated development set из12RU,
  не blind benchmark. Дополнительные4KK — отдельная оценка; live-понимание языка и
  native-speaker проверка не выполнены. NumericalPASS не заменяет semantic gate:
  `pnpm eval:retrieval` честно возвращает exit1.
- 298 POI — сохранённый срез, не весь город и не live-справочник. Все цены и свойства
  вроде розеток/тишины неизвестны; строгие требования исключают такие места.
  Бюджет0 означает только подтверждённо бесплатные места; пустое поле — без лимита.
  Поэтому0 исключает весь текущий каталог с неизвестной ценой.
  Расписание историческое, без праздничных исключений и гарантии фактической работы.
  Расстояние — по прямой, время посещения — оценка, дорога рассчитывается картами.
- 591 короткая буквальная выдержка отзывов — мнения, не подтверждённые свойства.
  Источник — карточка филиала, не проверенный permalink конкретного отзыва.
  Сбор данных не устанавливает право на публикацию чужого текста; такое право
  отдельно не подтверждено. Фото, авторы, контакты и полные raw-тексты не включены.
- Пройдены Chromium-сценарии390/1440 и focus/keyboard проверки. Пользователь подтвердил
  сайт и 3 карточки на физическом телефоне после снятия бюджета0. Обе кнопки
  2ГИС/Google Maps открыли выбранный Ботанический сад в приложениях по сообщению пользователя.
  Подтверждение относится к той же сборке на прежнем адресе; новыйURL проверен
  через Chromium390/1440, физический повтор ожидается. Отдельные Safari/iPhone
  и Android/Chrome проверки не выполнены.
  Проверки HTTPS href и координат выполнены отдельно в Chromium.
- Три профиля — явно обозначенные учебные предпочтения, не история реального человека.
  localStorage содержит только выбранный профиль и ID мест; это не аккаунт и не sync.
  Новый браузер начинает без профиля. При запрете storage изменения живут на экране.
- Голос пропущен по P1 gate: записи, распознавания и аудио endpoint нет. Подготовленное
  видео — без звука. Никакие пользовательские аудиозаписи не сохранялись.
- OpenRouter расход проекта$0, баланс аккаунта не проверен. Потолок подготовки$2,
  live-eval$0.50 внутри него, демо-резерв$4 сохранён. Guard проверен; paid выключен,
  реальный ledger не инициализирован. Текущий guard не поддерживает paid serverless.
  Haiku conservative reserve$1.32 превышает eval cap, лимиты не повышались.
- Публичное демо проверено как временный QuickTunnel от локальной production-сборки.
  Оно зависит от работающих Mac, origin-процесса, туннеля и сети; это не постоянный
  hosting/SLA. Фактический URL и проверка доступа записаны в [links.md](links.md).
  Код и PPTX опубликованы в GitHub по прямому запросу пользователя обычным push
  в main. Видео остаётся локальным; YouTube upload и отправка заявки не выполнялись.
